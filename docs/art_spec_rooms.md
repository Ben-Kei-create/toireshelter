# 美術仕様書（3 部屋）— 参考 3 枚から、実機で再現するものを絞る

参考：宮殿風の浴室／夜のおばあちゃんの部屋（和室）／夜の自室。美術の方向は 8／10。
**画像を増やすより、まず浴室 1 室を、この方向で仕上げる。** 以降の部屋は、その基準に合わせる。

## 0. 共通の原則（全部屋）
1. **置いた理由を一つずつ決める**：なぜそこにある／誰が使った／何を調べてほしいか。決められない物は置かない。
2. **見分けやすさを優先**：重要品（鍵・コイン・メモ・手がかり）は、背景より**明るい or 彩度が高い**。周囲に余白。
3. **暗く茶色に寄りすぎない**：通路・操作対象・床の縁が、暗い画面でも分かる明度差を残す。
4. 色は 4 系統に絞る：深紅／黒（漆・大理石）／古い金／暖色の灯り。夜の窓は**青**で差を作る。
5. 汚れ・古さは「**使い込み**」として見せる（生活の跡）。ただの汚しにしない。

## 1. 浴室（顔になる部屋）
- 色：壁＝深紅のダマスク（織り柄は細かく）、腰壁＝黒大理石＋金の枠、床＝黒白の市松（つや）、陶器＝**白〜クリーム**、金具＝真鍮、タオル＝深い赤。
- 灯り：シャンデリア（暖色）を主光源。陰影は強めでも、**床・浴槽の縁・手がかりが見える**明るさを保つ。
- 質感：陶器＝つや、金＝金属感（反射）、壁＝ビロードの毛羽（光を吸う）、大理石＝筋。
- 意味づけ：
  - ひまわりの絵：「誰かが飾った絵」。下のボタンは、**触りたくなる位置と大きさ**。
  - 身長計：ドア枠。家族の記録のように（鉛筆の線と日付を足す案）。
  - 鏡の飾り枠：実用の鏡（手かがみが刺さる）。
- **異常の出し方（検討事項）**：紹介文は「日常が少しずつおかしくなる」。浴室が**最初から豪華**だと矛盾する。
  - 案 A（今）：最初から異様に豪華。「狭いのに宮殿」が顔。紹介文を「いつものはずの浴室が、なぜか宮殿」に寄せる。
  - 案 B：最初は**ふつうのユニットバス**の質感（白・薄い黄）で、浮上の**後**に宮殿へ変わる。異変が段階的。
  - 案 C：最初は**少しだけ**豪華（金の蛇口・赤いタオル）で、探索のたびに壁・床が重なる。
  → あなたの判断待ち。推奨は **案 C**（紹介文と一致し、変化が遊びの報酬になる）。

## 2. おばあちゃんの部屋（和室：記憶・ぬくもり・不在）
- ホラーの定番（仏壇・写真・暗い穴）に**寄りすぎない**。**その人固有**の日用品を足す：
  - 使い込んだ急須・湯のみ（欠けた縁）、老眼鏡と読みかけの文庫、毛糸と編みかけのもの、茶箪笥の飴の缶、カレンダー（○印）、座布団のへこみ。
  - 「出ていくと決めた人」の跡：**片づけかけの荷物**（風呂敷包み）、減った薬、置き手紙の下書き。
- 灯り：中央の紙の提灯（暖色）、行灯、月あかりの障子（青）。**暖色と青の対比**で、物の輪郭を出す。
- 見分け：手がかり（掛け軸・家宝・はしご・コイン）の周りは暗くしすぎない。

## 3. 自分の部屋（帰りたい場所・生活感）
- 整いすぎを崩す：**途中までしていた行動**が分かる配置：
  - 開いたままの教科書とレポート（途中）、洗濯物のたたみかけ、飲みかけの麦茶、ギターのチューニング途中（ペグに手拭い）。
  - **コタニの痕跡**（実装済み）と、主人公の**好み**（レコード、水槽、釣り道具、植物）を並べる。
- 色：床＝つやのある飴色、こたつ布団＝深い赤、じゅうたん＝ペルシャ柄、電球色＝橙、窓＝青。
- 見分け：床の小物は、ラグ・床との**明度差**を取る。

## 4. 明るさと見分けの基準（実機での確認項目）
- [ ] 手がかり・拾える物が、**画面の端でも**目に入る（明度差）。
- [ ] 通路・段差・縁が、暗い場面でも分かる。
- [ ] 文字（メモ・ラベル）は、**実際の表示サイズ**で読める（全点を撮影して確認）。
- [ ] 重要品の周囲に**余白**（装飾の密集を崩す）。
- [ ] 色覚への配慮：赤と黒だけで重要度を示さない（形・光でも示す）。

## 5. 作業の順（案）
1. 浴室 1 室を、上の仕様どおりに仕上げる（異常の出し方を決める → 質感・灯り → 意味づけ → 撮影確認）。
2. 実機画面を撮影して、参考画像と並べる（差の洗い出し）。
3. 和室・自室へ展開（日用品・途中の行動を足す）。
4. 画像素材（壁・床・腰壁の質感、メモ・日記）を**一組**として生成して差し替える。
