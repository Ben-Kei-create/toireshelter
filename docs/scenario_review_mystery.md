# シナリオ v3 講評：ミステリーゲームのシナリオライターの目で

対象：`docs/scenario_toilet_v3.md`（v3〜v3.9）。難易度を少し上げ、こだわりを増やし、仕掛けを増幅する提案つき。

---

## 0. 結論（先に）

- **骨格はとても良い。** 閉じた世界、置かれた物がぜんぶ後で効く（チェーホフの銃）、一方通行の事件（部屋が上がる、松明を捨てる）、二つの結末。ここは崩さない。
- **ただし「取りに行く・運ぶ」の連続が長すぎる。** 謎が解ける快感より、お使いの疲れが先に来る危険がある。
- **一番の弱点は九蓮宝燈。** 運で出る役を「謎の答え」にしてはいけない（後述）。
- **統一テーマがすでにある。** 「水に流す／溶ける」。栓、お湯、玉、せっけん、毛だまり、悪口本、炭酸。これを**意識して全体に通す**と、ただの小ネタ集から一本の物語になる。

## 1. プレイ時間の見積もり

| 区間 | 初見（ヒントなし寄り） | 慣れた人 |
|---|---|---|
| 第1幕 ユニットバス（栓の連鎖→ドライバー→戸棚） | 40〜60 分 | 8 分 |
| 部屋が上がる→換気口→ベランダ→釣り→松明 | 40〜60 分 | 10 分 |
| 暗い部屋→カーテン→ホール→小さな扉→ブレーカー | 30〜45 分 | 8 分 |
| 宝石→ツルハシ→壁→隣の和室（家宝まで） | 45〜70 分 | 10 分 |
| トイレへ戻る（悪口本・数字・鏡文字・トランプ）→黒電話・水槽・金庫 | 45〜70 分 | 12 分 |
| 射的・つかみ取り→家の鍵→（ここで通常クリア） | 30〜45 分 | 8 分 |
| 吹き矢・九蓮宝燈・TKG・百円→自販機（真のクリア） | 45〜90 分 | 12 分 |
| **合計** | **約 4.5〜6.5 時間** | **約 1.5〜2 時間** |

- 難しめにしたい今の方針なら、**初見で 5〜7 時間**になる。インディーズの脱出ものとしては**長い**。目標を **3〜4 時間（初見）** に置くなら、後述の「削る」を採る。
- 通常クリア（家の鍵まで）は初見 **3〜4 時間**に収まる。**真のクリアは「やり込み」**という位置づけが健全。

## 2. 講評（良い所）

1. **一本の線に見えて、実は網。** ドライバーが「ドア・戸棚・格子」の 3 箇所で効く、ライターが「ブレーカー・隣の和室」で効く、など**一つの物が複数の場面で効く**のは理想的。
2. **時間と状態の謎。** お湯（温度と水位）、停電と部屋のスイッチ、青い光、一方通行の出来事。**状態が変わる謎**は、鍵と扉の謎より記憶に残る。
3. **二つの結末の設計。** 百円を持たずに出るとクリア、だが先がある。「**知らずに終わった人**」が後で気づく作りは強い。
4. **ふざけと本気の混在。** 悪口本、おふくろのTKG、炭酸リンゴ。**やさしいおかしさ**がある。ここが個性。

## 3. 講評（危ない所）

| # | 問題 | 直し方 |
|---|---|---|
| 1 | **九蓮宝燈は運**。出なければ詰む（または、永遠に回す） | **配牌を固定**し、「**どの牌を捨てれば九蓮宝燈の形になるか**」を考える**詰め麻雀パズル**にする。望遠鏡で見た文字＝そのヒント。何通りも作れない一意の解にする |
| 2 | **お使いが長い**（取る→運ぶ→使う） | 1 つの場所で**取得と使用を近く**する。運搬は、同じ階層（トイレ、ホール、部屋）の中で完結させる |
| 3 | **パスワードが多すぎる**（数字・英語・トランプ・栞の 4 つ） | 数を減らさず、**自動メモ（推理ノート）**を必須にして、解く楽しさを「**手がかりを結ぶ**」に移す |
| 4 | **取り返しのつかない出来事**（松明を捨てる、トイレを詰まらせる、はしごの設置） | 詰みを防ぐ。**釣りの救済**は良い案。ほかに、**どの一方通行でも、必要な物は必ず複数の入手経路**を持たせる |
| 5 | **景品のヒントが多い**（5 つ中 4 つがヒント） | 難しめにするなら、**ヒントの景品は「ヒントの質」を上げる**（答えでなく「方向」を示す）。または、**ヒントを見ない／見る**をプレイヤーが選べる |
| 6 | **同じ小道具の重複**（芯は望遠鏡と吹き矢） | 芯を 2 つにしたのは良い判断。**どちらにどの芯か**を、プレイヤーが自分で試すと**失敗の学び**になる |

## 4. 難易度を上げる：仕掛けの増幅案

### A. 「水に流す」を全体の主題にする（採用を強く勧める）
- 冒頭：**服の毛だまり**（流す）→ 栓 → 玉・せっけん（溶かす）→ **悪口本**（流す）→ **炭酸リンゴ**（弾ける水）。
- 主人公の独り言に『なぜ鍵を分けてしまったのか』とある。**「悔い／許す」**を縦糸にすると、**最後の一言**に意味が出る。例：自販機の前で『……あの鍵のことは、水に流そう。』
- 神の声の正体を最後に明かす案（例：**おふくろ**の声）。TKG の写真・家宝・隣の和室の質素さが、**一本の線**でつながる（隣の和室＝母の部屋、など）。※この方向は、ユーザー判断。

### B. 謎を「解く」にする仕掛け（お使いを減らす）
1. **短編集の縦読み**：悪口本以外の本（短編集）の**各話の頭文字**が、鏡文字の英単語や水槽の文字錠の答えになる。**自分で気づく**ように、巻末に目印は置かない（神の声のヒントでだけ示唆）。
2. **電力の配分パズル**：ヒューズは**1 本**。自分の部屋・隣の和室・トイレのどこに電気を回すか。トイレの照明は別系統だが、**シャワーのお湯**（電気温水器）は**部屋の電気**を使う、などにして、**ヒューズの置き場所を考える**。
3. **KO線の時刻表**：ゆっくりした電車が**決まった時刻**に通る。通過中は、**窓の光が部屋の壁に流れ**、暗い部屋の壁の**隠し文字**（蓄光塗料／影絵）が一瞬見える。時刻表は**看板**か**駅の貼り紙**にあり、吹き矢の看板の近く。
4. **水位の謎**：浴槽と洗面台の**水位の違い**で、せっけんの溶ける速さが変わる。湯の温度で、**溶ける時間が変わる**（お湯だと早い）。**待つ**ことを謎にする。
5. **音の謎**：黒電話の返却口の音、換気口の通気音（ダクトの分岐のどちらが隣家に近いか、音の大きさで分かる）。
6. **視点の謎**：布団で寝ると見える天井の点（望遠鏡）、シャワーを持って見上げる、トイレに座った目線。**姿勢を変えると見える**ものを増やす（すでに強い特徴）。

### C. こだわり（世界の厚み）
- **メッセージの紙**：シャワーのカーテンの数字、鏡文字、トランプ。**三つとも別の物理現象**（濡れる、反射、青い光）で見える。これは**完璧**。もう一つ、**熱で見える**（ライターの炙り出し、レモン汁の文字）を足すと四つ目として**家宝の写真の裏**（レシピ）に使える。
- **音と環境音**：停電中は、冷蔵庫の唸りが止まる。電気が戻った瞬間の**冷蔵庫の再起動音**で、プレイヤーに**達成が音で伝わる**。
- **トイレの詰まり**：詰まったあと、**ごぼごぼ音**が部屋の排水から聞こえる。些細だが、**世界が繋がっている**手触り。
- **KO線**：窓の外の電車の**車内に人影**（何人か、読書している）。一人だけ、**こちらに手を振る**（二回目以降）。物語のスパイス。

### D. 失敗を楽しくする
- **失敗に反応**を用意する（火事の元のマッチ箱：松明を部屋で振ると、火災報知器が鳴る→止めるとコミカル）。**詰まない失敗**だけを、笑える形で。
- 神の声は、たまに**間違った助言**をする（ただし、ヒント表示は常に正しい）。**遊びのスパイス**。

## 5. 削る・縮める案（目標 3〜4 時間にするなら）

| 案 | 効果 |
|---|---|
| 栓の連鎖（洗面台→せっけん→おもり→浴槽）を、**2 段（せっけん→おもり）**に縮める | −15 分 |
| 景品 1〜5 のうち**ヒント 2 つを削る**（景品 2, 3 は、同じ事柄を指すヒントなら統合） | −10 分 |
| コイン 5〜7 のうち 1 つを**隣の和室の中で完結**にする（取りに戻る往復を減らす） | −20 分 |
| 九蓮宝燈を**詰め麻雀**にして、確実に 1 通りで解ける | 運の時間の削除 |
| 吹き矢の看板を**ベランダから一発で見える位置**に置く | −10 分 |

## 6. 推奨：実装の前にやること

1. **パスワードと手がかりの一覧**（全部の「見る→読む→入力」を 1 枚に）。**推理ノート**の設計も、この表から作る。
2. **詰み防止の確認表**（一方通行の出来事ごとに、必要な物の入手経路）。
3. **九蓮宝燈の詰め麻雀の問題**（一意解）を先に作って検証する。
4. **段階 1〜2 を先に実装して、通しで遊ぶ**（時間計測）。そこで 4.5 時間の見積もりが当たるか確かめて、後半の仕掛けの量を決める。
