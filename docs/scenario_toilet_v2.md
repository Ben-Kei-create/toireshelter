# トイレ（ユニットバス）脱出シナリオ 直し版（v2）

前の案の「流れの気持ちよさ」を残しつつ、**いまのゲームの設備・設定に合わせて直した版**。
（太字の「判断」は、こちらで決めた仮の決定。変えたいときは言ってほしい。）

---

## 0. 直しの要点（前の案からの変更）

| 前の案 | 直し版 |
|---|---|
| 外から施錠され、全く動かない扉 | ノブが**空回り**するだけ（ネジがゆるんでいる）。**現状の設定のまま** |
| 洗面台の下の床の排水口 | **洗面台のボウルの「縁の穴（オーバーフロー）」**と、栓・水位（既存の設備） |
| 10円玉でネジ（ドライバーが別にあるのに） | **ドライバーは撤去**し、**十円玉が「ドライバー」の役**（ドア・鏡の留め具・換気口のネジ、全部これ） |
| 浴槽の縁に立って天井に手を伸ばす | **浴槽に入って（E）**、格子を狙い、ネジを回す（いまの導線のまま） |
| 一番熱いお湯で鏡が曇る | **シャワー（お湯）を出し続けると湯気がたまり**、鏡に文字が浮かぶ（新規の演出） |
| 鏡の文字が命令文 | **名詞だけ**の短い言葉に変更（閃きを残す） |
| 脱出口が換気口の 1 本 | **同じ十円玉で、ドア（裏技）か換気口（正規）かを選べる**（2 本のルートを維持） |

## 1. 判断（こちらの仮の決定）

1. **ドライバーは撤去する。**（床の落とし物をなくし、洗面台の調べる文章を差し替える）
2. 道具は**十円玉 1 つだけ**。ドア・鏡の戸棚の留め具・換気口の格子、すべて「十円玉を選んで F」。
3. **ルートは 2 本維持**：ドア（裏技）と換気口（正規）。十円玉までの流れは共通で、最後に分かれる。
4. **新しい持ち物は 3 つ**：ゴム栓、カプセル（その場で開けて十円玉になる）、十円玉。拾った時点で持ち物欄に入る（最大 8 つのうち）。
5. インターホンは**そのまま**（24 時台のみ）。冒頭には増やさない。
6. **失敗はない。** やり直しは、いつでも同じ手順で可能。

## 2. 全体の流れ（5 段＋分岐）

```
①状況把握 → ②鏡（シャワーの湯気）→ ③芯の中（ゴム栓）→ ④洗面台（栓・水・縁の穴）→ ⑤カプセル → 十円玉
                                                                              ├→ ドアのネジを締める → ドアが開く（裏技ルート）
                                                                              └→ 浴槽から格子のネジを外す → 換気口（正規ルート）
```

### ① 状況把握（導入）
- **見えること**：床のタイル、便器、洗面台、浴槽。天井に**格子のついた換気口**（四隅に、平たい溝のネジが 4 本）。
- **できること**：ドアのノブを回す →「ドアノブが空回りする。開かない。」ネジは見えるが、**指では回らない**（溝が固い）。
- **手がかり（既存）**：浴槽の紙『ここまで来たか。』、棚の裏の紙『下からなら見える。』、タンク下の紙『しゃがむと、いろいろ見える。』。
- **気づくこと**：ネジを回す「何か平たい物」が要る。

### ② 鏡の湯気（読ませる）
- **操作**：シャワーを出す（水の勢いが続くと、熱いお湯の湯気が部屋にたまる。**ドアが閉まっていること**）。**約 8 秒**で、東の壁の**鏡**が白く曇り、曇り止めの塗られた部分だけが透けて**文字**が浮かぶ。
  - 浮かぶ文字（**短い名詞 2 行**）：
    - 『芯のなか』
    - 『ふちのあな』
- シャワーを止めて約 20 秒で、文字は消える（読み逃したら、もう一度出す）。
- 鏡の下の戸棚は、いままで通り留め具で施錠（十円玉で外せる。中身は飾り）。

### ③ トイレットペーパーの芯
- **前提（既存）**：ホルダーは**芯だけ**で、カバーは閉じている。
- **操作**：カバーを開け（既存）、**芯を調べる**（クリック）。→「芯の中に、何か詰まっている。」→ もう一度クリックで、**ゴム栓**を取り出す（持ち物）。
- 文章：「小さなゴムの栓だ。洗面台の栓に似ている。」

### ④ 洗面台（栓・水・縁の穴）
- **初期状態の変更（新規）**：洗面台の栓は**最初からない**（チェーンだけが切れて垂れている）。→「栓がない。水を出しても、そのまま流れていく。」
- **手がかり（新規）**：洗面台を調べる →「小さな洗面台。縁の穴の奥で、何かが光った気がする。」しゃがむ／近づくと、縁の穴（オーバーフロー）の内側に丸い影。
- **操作**：
  1. ゴム栓を選んで、**排水口を狙って F**（栓をする）。→「ぴったりはまった。」
  2. **蛇口を出す**（既存）。水位が上がる。
  3. 水位が**縁の穴の高さ**になると、穴の奥から**カプセル**が「ぽこっ」と浮いて出てくる。
  4. 水を止めてもよい。カプセルを**クリックで拾う**。
- 文章：「縁の穴から、丸いカプセルが浮かんできた。ガチャガチャの空き容器みたいだ。」

### ⑤ カプセル → 十円玉
- **操作**：カプセルを選んで、**もう一度クリック**（その場で開ける）。→「パカッ。中から、十円玉が出てきた。」十円玉を持ち物に入れ、カプセルは消える。
- 文章：「ずいぶん古い十円玉だ。縁が、マイナスのドライバーみたいに薄い。」

### 分岐
- **裏技ルート（ドア）**：十円玉を選び、**ドアのノブのネジ**を狙って F。→「十円玉でネジを締め直した。……ドアが開いた！」（以降は、現状どおり。玄関ホール → 玄関ドア。）
- **正規ルート（換気口）**：**浴槽に入り（E）**、天井の**格子のネジ**を狙って、十円玉を選んで F。
  - 1 回の F で、4 本のネジを順に回す演出（短い効果音を 4 回）。→「ガコッ。格子が外れた。」
  - 浴槽の中で、換気口を狙って **E：換気口へ入る**（既存の導線）。以降は、ダクト → ベランダ。
  - 十円玉なしで、格子を狙って E →「格子は、ネジで留まっている。」

## 3. 文章（そのまま実装できる形）

### 神の声のヒント（放置 55 秒で、段ごとに 1 つ。出したら二度と出ない）
| 段 | 条件 | 文章（神の声。40 文字以内） |
|---|---|---|
| ① | 最初から（シャワーを使っていない） | 「ネジを回すものが、どこかにあるはずだ。」 |
| ② | 鏡を見ていない・シャワーを使っていない | 「熱いお湯が出る。鏡が、曇るかもしれない。」 |
| ② | 鏡の文字を読んだが、芯を調べていない | 「芯のなか……。ペーパーの芯が、気になる。」 |
| ③ | ゴム栓を持っていて、洗面台に栓をしていない | 「ゴム栓。洗面台の栓に、似ていないか？」 |
| ④ | 栓をしたが、水が溜まっていない | 「縁の穴まで、水を溜めてみよう。」 |
| ⑤ | カプセルを持っていて、開けていない | 「カプセルは、開けるためにある。」 |
| 分岐 | 十円玉を持っていて、何も使っていない | 「ネジが、ふたつある。ドアと、天井に。」 |

（既存の「焦らなくていい」は、全部出したあとの最後に出る。）

### 調べたときの文章（新規・変更）
- **洗面台（変更）**：「小さな洗面台。縁の穴の奥で、何かが光った気がする。」
- **洗面台の栓の穴（新規、栓なしのとき）**：「栓がない。水を出しても、そのまま流れていく。」
- **ホルダーの芯（変更）**：「芯だけになっている。紙がない。……中に、何か詰まっている。」
- **ドアのノブ（変更）**：「ドアノブが空回りする。ネジがゆるんでいるようだ。」（ドライバーの言及をなくす）
- **換気口の格子（変更）**：「格子の四隅に、平たい溝のネジが見える。指では回らない。」
- **鏡（湯気のとき）**：文字だけ（上の 2 行）。調べると「湯気の中に、文字が透けている。」

### 発見の知らせ（右上。8 文字程度）
- 「鏡の文字」（鏡に文字が出たとき）／「ゴム栓」／「縁の穴」／「カプセル」／「十円玉」／「換気口の格子」
