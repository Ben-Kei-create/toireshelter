# 欲しい画像のリスト（雑貨・小物）

いまはコードで描いた簡単な絵（または無地の色）になっているもの。画像があれば差し替えて細部が上がる。
形式はどれも PNG。「透過」と書いたものは背景を透明にしてもらうと貼りやすい（背景が単色なら、こちらで切り抜く）。文字を入れる絵は日本語でも英字でもよい（実在のロゴ・商標は入れない）。

## 主人公（キャラクター）
- 切り抜き済み：`assets/textures/character/`（全身 5 方向、顔のアップ 3 方向）。
- 追加で欲しいなら：①顔のアップの「うつむき」「目を閉じた」②手のアップ（指輪つき）③後ろ姿の髪（等身大パネルの裏）④鏡に映る上半身（肩から上）の別ポーズ。

## 描いてもらうときのお願い
- 透過 PNG（背景なし）か、背景が単色の PNG。
- 暗い絵は少し明るめに（部屋の照明が電球色で薄暗いため）。
- 画像に実在のブランド名・ロゴ・既存キャラクターは入れない。
