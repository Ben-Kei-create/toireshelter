# トイレ（ユニットバス）脱出シナリオ v3

v2 からの変更：ドライバーは残す／十円玉・カプセル・ゴム栓の連鎖はやめる／入浴剤の玉からドライバー／届かなければ届かない（足場が要る）／ユニットバスが「ゴゴゴ」と上がる。
（**判断**と書いた所は仮の決定。変えたいときは言ってほしい。）

## 1. 決まっていること（ユーザー指定）

1. **ドライバーは鏡の戸棚のカギ**。ドアノブのネジ・換気口の格子のネジも、同じドライバー。
2. ドライバーは**バスロマン（入浴剤）の中の玉**に隠れている。玉は**お湯でだけ溶ける**（お湯はり、または追い焚き）。水だと色は変わるが、固い玉は溶けない。溶けきると、ドライバーが現れる。
3. 換気口は**物理的に届かないといけない**。足場（裏返したバケツ）に乗る。
   - **小ネタ**：目の高さを最大（170 cm）にして換気口を狙うと、足場なしでも E で入れる。
4. 最後に**ユニットバスの部屋そのものが「ゴゴゴ」とゆっくり上がる**（天井が下がるのではない）。上がったまま戻らない。ドアの外へ降りて自分の部屋へ行けるが、**もう戻れない**。
5. 換気口からも出られる。ダクト → ベランダ → 窓から部屋へ回る。
6. 玄関ホールから見て、**左手の部屋の入口に和室のようなスライド式のふすま**を 1 枚つける。一気に部屋の中が見えないように。

## 2. 全体の流れ

```
①状況把握 → ②お湯を張る/追い焚き → ③玉が溶ける → ④ドライバー
   ├→ ドアのネジ（ノブ）を締める → ドアが開く（近道）
   ├→ 鏡の戸棚を開ける → 中の「点検レバー」を引く → 部屋が上がる（ゴゴゴ）→ 降りる（戻れない）
   └→ バケツに乗る → 換気口の格子のネジを外す → ダクト → ベランダ → 部屋（正規）
```

**判断**：近道（ドア）と正規（換気口）は残す。「部屋が上がる」は、鏡の戸棚の中のレバーで起こす第 3 のルートにする（ストーリー上の見せ場）。上がったあと、ドアは開き、外は床が低くなっていて、降りるだけ。

### ① 状況把握
- ドアノブが空回り。ネジがゆるんでいるが、指では回らない。
- 鏡の戸棚は留め具で施錠。換気口は高く、格子に平たい溝のネジが 4 本。
- 紙の手がかり（既存）：『下からなら見える。』『しゃがむと、いろいろ見える。』『ここまで来たか。』

### ② お湯（鍵）
- 棚の上のバスロマンを取る（既存）。浴槽に入れる（既存の入浴剤の処理）。
- **水の状態**：色がつく。丸い玉は沈んで残る。「玉のようなものが、底に沈んでいる。溶けそうにない。」
- **お湯の状態**（お湯はり、または追い焚きで温かくなったとき）：玉が少しずつ溶ける。約 20 秒。
- 浴槽の水位が足りないと、玉は水に浸からず、溶けない（既存の最小水位をそのまま使う）。

### ③ 玉が溶ける
- 泡と湯気。湯気が鏡を曇らせ、文字が浮かぶ（任意）。**判断**：浮かぶ言葉は名詞だけ。『ゆず』『あたたかい湯』『玉』。
- 溶け残りの中から、**ドライバー**が現れる（浴槽の底。拾える）。「玉の中に、ドライバーが入っていた。」

### ④ 使い道
- **ドアノブ**（ネジ）：締めてドアが開く。近道。
- **鏡の戸棚**（留め具）：外すと開く。中に洗顔料・化粧水・綿棒（既存）と、奥に**点検レバー**（赤い小さな取っ手）。
- **換気口の格子**：ネジを外す。外してから足場に乗って入る。

### ⑤ ゴゴゴ（部屋が上がる）
- 点検レバーを引く：「ガコン」。壁と床が震え、音と揺れが約 8 秒続く。窓のない部屋の中で、水面がかすかに傾く。
- 揺れが止まるとドアが開く（ドアの外が暗く、床が下にある）。ドアの外に出ると、**ゆっくり降りる**（フェード）。ホールに立つ。
- 戻ると、ユニットバスのドアは**もう届かない高さ**（入口の向こうは壁）。**戻れない**。
- 換気口ルートで出てきた場合も、ベランダ → 窓 → 部屋に回れる。部屋が上がったかどうかは関係ない。

### ⑥ 足場
- ドアの近くのバケツ（既存の小道具）を、**裏返す**（クリック：「バケツを裏返した。上に乗れそうだ。」）。
- 乗る（E）：目の高さが +40 cm、動けない姿勢。換気口を狙って E で入る。降りるのは移動キーか E。
- 小ネタ：目の高さを最大にして換気口を狙う → 足場なしで E で入れる。文章：「背伸びをしたら、ぎりぎり届いた。」

# 追補（v3.1）：栓の連鎖と、正規ルートの導入

ユーザー追加指定：①便座に座ると手がかりが得られる（正規ルートの導入）／②しゃがむと便器の後ろの張り紙が読める（ヒントの紙）／③タオルの後ろに傷／④浴槽の栓をなくす／⑤洗面台の栓もない／⑥十円玉を洗面台の栓にして水を溜め、水で何かを溶かして「重たい何か」を得る→それで浴槽の栓ができる。

## A. 導入の手がかり（正規ルートの入口）

| 場所 | 操作 | 内容（**判断**＝仮の文章） |
|---|---|---|
| 便座 | 座る（既存の座る姿勢）→ 前を見る | 座った目線でだけ、ドアの内側の低い位置に貼り紙が見える。『湯は、ためてこそ。』 |
| 便器の後ろ | しゃがむ（既存の紙の位置） | 張り紙（ヒントの紙）『栓がない。軽いものは、浮く。』 |
| タオル | タオルをめくる／どける（調べる 2 回目） | 後ろの壁に引っかいた傷。丸い（十円玉の大きさ）くぼみと、その下に五本線（水の波）。傷の中に十円玉が挟まっている（拾える）。 |

調べた文章：タオル『タオルの後ろの壁に、傷がある。丸い形が、刻まれている。』／拾う『古い十円玉が、傷のくぼみに挟まっていた。』

## B. 栓の連鎖（すべて「水が溜まる」を軸にする）

```
十円玉（タオルの後ろ）→ 洗面台の排水口にふたをして水を溜める
   → 固形せっけん（棚の上）を水に沈める → 溶ける（約 30 秒。水でよい）
   → 中から鉛のおもり（重い）が出る → 洗面台の水を抜く（十円玉が戻る）
   → 浴槽の排水口に十円玉でふた＋おもりを載せる → 水がちゃんと溜まる
   → お湯はり／追い焚きが使える → バスロマンの玉が溶ける → ドライバー
```

- **浴槽の栓**：最初から**ない**。調べると『栓がない。穴から水が抜けていく。』
- **十円玉だけで浴槽の排水口にふた**をすると、すこし溜まるが、**十円玉が浮いてしまい**、水位が一定（低い高さ）より上がらない。お湯はり・追い焚き・入浴剤は**最小水位に届かず使えない**。『十円玉が浮いてしまう。重さが足りない。』
- **おもりを十円玉の上に載せる**と、ふたが安定し、水位が上がる。
- **洗面台の栓**：これも最初から**ない**。十円玉を排水口に置くとふたになり、水が溜まる（水を出したまま、が条件）。
- **固形せっけん**：棚の上のクリーナー・予備ロールの並びに追加（新規の小道具）。**水を溜めた洗面台に入れる**と、泡が出てゆっくり小さくなり、溶けきるとおもりが沈んで残る。『せっけんが溶けて、中から重たい鉛のおもりが出てきた。』
- ドライバー入りの玉（バスロマン）は、**お湯でだけ**溶ける（v3 のとおり）。

## C. 全体の順序（ゲート）

1. 手がかり（座る・しゃがむ・タオル）→ 十円玉
2. 洗面台に十円玉でふた → 水 → 固形せっけん → おもり
3. 浴槽にふた＋おもり → お湯 → バスロマン → 玉が溶ける → ドライバー
4. ドライバーの使い道（ドアノブ／鏡の戸棚→点検レバー／換気口の格子＋バケツの足場）

2. 溶かす物は**固形せっけん→鉛のおもり**でよいか（別案：棚の固形洗剤、氷のようなもの）。
3. 浴槽のふたが浮く演出は、**水位の上限が低いまま**で表現する。

# 追補（v3.2）：全体の動線（トイレ → 通気口 → ベランダ → 部屋 → 玄関側）

ユーザー指定の動線。v3 / v3.1 と食い違う所は、この追補を優先する。

## 0. v3 / v3.1 からの変更点

| 以前 | v3.2 |
|---|---|
| ドアのネジを締めて出る近道 | **廃止**。ドアは、部屋が上がるときに壊れる。ノブは空回りのまま |
| 部屋が上がったあと、自分の部屋へ降りられる | **降りられない**。玄関側へ出られず、上から**覗くだけ**。出口は通気口のみ |
| 点検レバー＝第 3 のルート | **レバー（ドライバーで開けた鏡の戸棚の奥）＝唯一の進行のきっかけ**。引くと部屋が上がる |
| 通気口 → ダクト → ベランダ → 窓から部屋 | ベランダの窓は**鍵がかかっている**。鍵が先に要る |

## 1. 動線（章立て）

### 第 1 幕：ユニットバス（v3 / v3.1 の栓の連鎖）
十円玉 → 洗面台の栓 → せっけん → おもり → 浴槽の栓 → お湯 → 玉が溶ける → **ドライバー**。
ドライバーで**鏡の戸棚**を開け、奥の**点検レバー**を引く。

### 第 2 幕：部屋が上がる（ゴゴゴ）
1. 約 8 秒、揺れと音。**ドアが内側からぶっ壊れる**（破片が飛ぶ）。
2. 壊れたドアの脇に、**木の棒**（枠の破片）が落ちている。拾える（のちに松明の柄）。
3. 扉の外は、**床が下にある**。玄関側（ホール）が見下ろせる。**降りられない**（高さ。手すりのない縁で、前に進めない／見えない壁）。ホールの床に**壊れたドアノブ**が転がっているのが見える（「ドアノブ。……届かない。」）。**ここでは拾えない**。
4. 部屋から**ユニットバスには戻れない**（ホールからは、上がった部分に届かない）。
5. 出口は**換気口のみ**（v3 の足場で届かせる／最大の目の高さで E）。

### 第 3 幕：通気口
- 格子をドライバーで外し、入る（既存のダクト）。
- ダクトは**二手に分かれる**：
  - **A：ベランダ側**。途中に**ボロボロのはしご**があり、下ろすとベランダへ出られる（下ろしたら戻れる）。
  - **B：真っ暗な通気口**（隣の住民の部屋の通気口へつながる。隣の部屋は作らない）。ある程度進めるが**暗すぎて先へ行けない**（明かりが必要）。『真っ暗だ。これ以上は、進めない。』

### 第 4 幕：ベランダ
- ベランダから部屋の**窓は施錠**。入れない。『部屋の鍵がかかっている。』
- ベランダの**下に、マッチ棒が落ちている**（手すりの外・下の段）。**釣り竿で拾う**（既存の釣り。コイン用の釣りの流れを使う）。
- **釣りで、かなりの確率で部屋の鍵も釣れる**（マッチ棒を釣る途中の、ふつうの当たりの 1 つ。確率は高め。数回で必ず出るようにする）。
- **ベランダのブレーカー**（フューズがない）。『ヒューズがない。』

### 第 5 幕：松明
- **木の棒 ＋ マッチ棒 → 松明**（持ち物で組み合わせる）。
- 松明で**真っ暗な通気口（B）**の先へ進む。ここは進めるが、**部屋の鍵**を手に入れる別の流れ（釣りで出なかった場合の保険）：奥の通気口の隅に**部屋の鍵**が落ちている。
- 主人公の独り言（神の声）：『なぜ、鍵をふたつに分けたのか……。』（部屋の鍵＝ベランダ→部屋でしか使えない。部屋から玄関側へ出るには、**まだ**別の鍵）

### 第 6 幕：部屋に入る（暗い部屋）
- ベランダの窓に**部屋の鍵**を使い、部屋へ。
- **部屋は停電で真っ暗**。松明の明かりだけ（半径の小さな明かり）。
- 部屋の物は**調べると説明が出るだけ**で、遊べない（コタツには入れない／ゲーム・レコード・麻雀・テレビ・寝る・冷蔵庫の食べ物、すべて使えない）。例：『こたつがある。電気がないと、暖かくない。』
- 部屋の玄関側（ホール）には、**ふすま**（v3）を開けて出られる。ホールの床に**壊れたドアノブ**がある（**ここで拾える**）。

### 第 7 幕：上がった部分の小さな扉
- ホールから見ると、浮き上がった部分に**小さな扉**が見える（ドアノブがない）。
- **ドアノブ**を取り付けて開ける。**入れはしない**が、中に**ヒューズ**がある。拾う。
- ヒューズを**ベランダのブレーカー**に入れる → **部屋の電気がつく**。

### 第 8 幕：部屋フェーズへ（次の章）
- 部屋が使えるようになる。**玄関の鍵（家の鍵）を探す**（部屋フェーズ）。
- 部屋の鍵・玄関の鍵は別物。玄関ドア（505）を開けて廊下へ出るのは、**家の鍵が見つかってから**。

# 追補（v3.6）：トイレへ戻る・隣の和室・ツルハシ・栞・望遠鏡

v3.2〜v3.5 の「トイレに戻れない」は、**後半は戻れる**に修正する。

## 1. 部屋の吊り下げ蛍光灯

- 部屋の蛍光灯は、**何度つけ消ししても青くならない**（普通の白のまま）。
- 青い光が必要な謎（白紙トランプ、宝石）は、**あえて、トイレへ行く手間**が発生する。

## 2. トイレへ戻る（後半）

- 上がったトイレは、**はしご**を手に入れると行ける。
- **はしごは、隣の和室で見つかる**。
- はしごは、ホール側の浮き上がった部分に**立てかけて**使う（小さな扉の近く）。上り下りできる。
- 序盤は戻れない（v3.2）。**はしごを手に入れてから**、トイレの設備（シャワー、鏡の紙、照明、手かがみ）を再び使える。

## 3. 手かがみと宝石（ツルハシ・結晶）

1. **手かがみ**は、最初は使わない。**トイレの鏡の中（戸棚）**にある（ドライバーで戸棚を開けて、取れる）。取るのは上がる前でもあと（はしごのあと）でもよい。
2. **部屋を暗くする**（停電のまま、または部屋のスイッチを切る）。
3. **トイレの照明を点けておく**（かつ、**何度かつけ消しして青にしておく**）。部屋が暗いので、トイレの青い光が、扉のあった縁からホール・部屋に**細く差し込む**。
4. 部屋の**宝石**（大きな宝石）に、**手かがみで青い光を反射**させる。
5. 宝石が**割れる**。**大きなツルハシ**と**結晶**が手に入る。

> 判断：トイレの照明は別系統（ユニットバス専用）で、停電でも点く。ただし、部屋が上がる前に、青にして点けておく必要はない（はしごで戻ったあとでもよい）。

## 4. ツルハシで隣の和室へ

1. ツルハシを持って、**こたつの中に入る**。
2. こたつの中を進んだ先の**壁**を、ツルハシで**壊す**。
3. **隣の和室**へ行けるようになる。

## 5. 隣の和室

- **暗くて質素**。**掛け軸**と**はしご**がある。ドアやトイレ（元のトイレ）へは行けるが、真っ暗で見えない。
- **隣の家にヒューズをつけても**（電気が戻っても）、**ほとんど見えない**。
- **ライター**（ブレーカーで得たもの）で**奥まで行く**と、**コインを 1 枚**手に入れる。→ **コイン 4 枚目**（v3.4 の未定枠の 1 つ）。
- **家宝**（パスワード式）がある。パスワードは**絵**（犬・猿・キジ、下の栞）。
- 掛け軸は、読める手がかり（案：犬・猿・キジの順番、桃の絵）。

## 6. 本と栞

- 部屋の**本**は、**何かの意味がある短編集**。
- **特定の本**を読む（開く）と**栞が挟まっている**。全部で **3 つ**出る。
- 栞のうち 1 つは、**犬・猿・キジの絵の栞**。これが**隣の和室の「家宝」のパスワード（イラスト）**。
- 残りの 2 つの栞は、**未定**（案：トイレの紙のヒント、九蓮宝燈の牌の絵、など）。

## 7. 布団と望遠鏡（九蓮宝燈のヒント）

1. **布団で寝る**と、天井に**何か気になるもの**（小さな点）が見える。
2. 宝石が割れて得た**結晶**と**トイレットペーパーの芯**を組み合わせて、**望遠鏡**ができる。
3. 望遠鏡で**その点**を覗くと、小さく**「九蓮宝燈」**と書かれている。→ 一人麻雀（v3.4）のヒント。

> 注意：**芯**は、**吹き矢**（v3.4）にも使う。**芯は 2 つ**必要：ホルダーの芯（既存）と、予備のロール（棚の上）を使い切った芯。**判断**：望遠鏡＝ホルダーの芯、吹き矢＝予備のロールの芯。

## 8. 更新後の動線（全体）

```
トイレ(栓の連鎖)→ドライバー→鏡の戸棚→手かがみ・レバー→部屋が上がる→換気口→ベランダ
→マッチ・鍵→松明→暗い部屋→カーテン・松明を捨てる→ホール(ふすま)→ドアノブ→小さな扉→ヒューズ
→ブレーカー(ねじ・ライター)→停電のまま：トイレの青い光＋手かがみで宝石→ツルハシ・結晶

→望遠鏡(結晶＋芯)→九蓮宝燈→麻雀(東・中)→メダル→つかみ取り→百円→自販機…（v3.4）
```

- **注意**：ヒューズを入れて電気がつくと、部屋は明るくなり、青い光が見えにくい。宝石の謎は、**電気を戻す前**に行う（または、部屋のスイッチで暗くできる）。

# 追補（v3.7）：漏れ光・栞・家宝・隣の家・ベランダの景色

## 1. トイレの漏れ光（宝石の謎の演出）

- 手かがみの反射は**簡易判定**（近づいて向きを合わせる）でよい。
- **部屋の電気が消えているとき**、トイレから**漏れ出る光**を**少しだけ強調**する（扉のあった縁から、ホールと部屋に細くのびる光）。
- トイレの照明が**青**のときは、**さらに強調**する。
- **部屋を明るくすると**（電気がつく／部屋のスイッチ）、漏れ光は**全くわからない**。→ 宝石の謎は、電気を戻す前（v3.6 のとおり）。

## 2. 栞（確定）

- 栞は 3 枚。**それぞれ 1 匹だけ**描かれている：**猿だけ**／**キジだけ**／**犬だけ**。
- 3 枚そろえると、**犬・猿・キジ**がそろう。**家宝のパスワード（イラスト 3 つの選択）**になる。
- 順番は、掛け軸の絵（案：犬 → 猿 → キジ）が手がかり。
- 栞は 3 冊の短編集それぞれに挟まっている（特定の本を読むと出る）。

## 3. 家宝の中身（確定）

- 家宝を開けると、「**おふくろのTKG**」と書かれた**写真**が入っている。
- 写真の**裏にレシピ**が書かれている：
  - **ご飯**と**卵**を組み合わせて、**「冷めたTKG」**を作る。
  - それを**電子レンジでチン**すると、**TKG**ができあがる。
- 内容は**それだけ**（写真とレシピ）。報酬や次の仕掛けはなし。
- **実装**：電子レンジは、いまは「調べるだけ」。**使えるようにする**（冷めたTKGを入れて温める）。ご飯と卵は、既存の食べ物（床下貯蔵庫など）から。完成した TKG は持ち物（食べると一言）。

- **家の鍵 ＝ つかみ取り 6 個目**（確定）。玄関ドアを開ける鍵。これで v3.4 の景品 6 の中身が決まる。
