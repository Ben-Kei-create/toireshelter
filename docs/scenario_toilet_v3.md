# トイレ（ユニットバス）脱出シナリオ v3

v2 からの変更：ドライバーは残す／十円玉・カプセル・ゴム栓の連鎖はやめる／入浴剤の玉からドライバー／届かなければ届かない（足場が要る）／ユニットバスが「ゴゴゴ」と上がる。
（**判断**と書いた所は仮の決定。変えたいときは言ってほしい。）

## 1. 決まっていること（ユーザー指定）

1. **ドライバーは鏡の戸棚のカギ**。ドアノブのネジ・換気口の格子のネジも、同じドライバー。
2. ドライバーは**バスロマン（入浴剤）の中の玉**に隠れている。玉は**お湯でだけ溶ける**（お湯はり、または追い焚き）。水だと色は変わるが、固い玉は溶けない。溶けきると、ドライバーが現れる。
3. 換気口は**物理的に届かないといけない**。足場（裏返したバケツ）に乗る。
   - **小ネタ**：目の高さを最大（170 cm）にして換気口を狙うと、足場なしでも E で入れる。
4. 最後に**ユニットバスの部屋そのものが「ゴゴゴ」とゆっくり上がる**（天井が下がるのではない）。上がったまま戻らない。ドアの外へ降りて自分の部屋へ行けるが、**もう戻れない**。
5. 換気口からも出られる。ダクト → ベランダ → 窓から部屋へ回る。
6. 玄関ホールから見て、**左手の部屋の入口に和室のようなスライド式のふすま**を 1 枚つける。一気に部屋の中が見えないように。

## 2. 全体の流れ

```
①状況把握 → ②お湯を張る/追い焚き → ③玉が溶ける → ④ドライバー
   ├→ ドアのネジ（ノブ）を締める → ドアが開く（近道）
   ├→ 鏡の戸棚を開ける → 中の「点検レバー」を引く → 部屋が上がる（ゴゴゴ）→ 降りる（戻れない）
   └→ バケツに乗る → 換気口の格子のネジを外す → ダクト → ベランダ → 部屋（正規）
```

**判断**：近道（ドア）と正規（換気口）は残す。「部屋が上がる」は、鏡の戸棚の中のレバーで起こす第 3 のルートにする（ストーリー上の見せ場）。上がったあと、ドアは開き、外は床が低くなっていて、降りるだけ。

### ① 状況把握
- ドアノブが空回り。ネジがゆるんでいるが、指では回らない。
- 鏡の戸棚は留め具で施錠。換気口は高く、格子に平たい溝のネジが 4 本。
- 紙の手がかり（既存）：『下からなら見える。』『しゃがむと、いろいろ見える。』『ここまで来たか。』

### ② お湯（鍵）
- 棚の上のバスロマンを取る（既存）。浴槽に入れる（既存の入浴剤の処理）。
- **水の状態**：色がつく。丸い玉は沈んで残る。「玉のようなものが、底に沈んでいる。溶けそうにない。」
- **お湯の状態**（お湯はり、または追い焚きで温かくなったとき）：玉が少しずつ溶ける。約 20 秒。
- 浴槽の水位が足りないと、玉は水に浸からず、溶けない（既存の最小水位をそのまま使う）。

### ③ 玉が溶ける
- 泡と湯気。湯気が鏡を曇らせ、文字が浮かぶ（任意）。**判断**：浮かぶ言葉は名詞だけ。『ゆず』『あたたかい湯』『玉』。
- 溶け残りの中から、**ドライバー**が現れる（浴槽の底。拾える）。「玉の中に、ドライバーが入っていた。」

### ④ 使い道
- **ドアノブ**（ネジ）：締めてドアが開く。近道。
- **鏡の戸棚**（留め具）：外すと開く。中に洗顔料・化粧水・綿棒（既存）と、奥に**点検レバー**（赤い小さな取っ手）。
- **換気口の格子**：ネジを外す。外してから足場に乗って入る。

### ⑤ ゴゴゴ（部屋が上がる）
- 点検レバーを引く：「ガコン」。壁と床が震え、音と揺れが約 8 秒続く。窓のない部屋の中で、水面がかすかに傾く。
- 揺れが止まるとドアが開く（ドアの外が暗く、床が下にある）。ドアの外に出ると、**ゆっくり降りる**（フェード）。ホールに立つ。
- 戻ると、ユニットバスのドアは**もう届かない高さ**（入口の向こうは壁）。**戻れない**。
- 換気口ルートで出てきた場合も、ベランダ → 窓 → 部屋に回れる。部屋が上がったかどうかは関係ない。

### ⑥ 足場
- ドアの近くのバケツ（既存の小道具）を、**裏返す**（クリック：「バケツを裏返した。上に乗れそうだ。」）。
- 乗る（E）：目の高さが +40 cm、動けない姿勢。換気口を狙って E で入る。降りるのは移動キーか E。
- 小ネタ：目の高さを最大にして換気口を狙う → 足場なしで E で入れる。文章：「背伸びをしたら、ぎりぎり届いた。」

# 追補（v3.1）：栓の連鎖と、正規ルートの導入

ユーザー追加指定：①便座に座ると手がかりが得られる（正規ルートの導入）／②しゃがむと便器の後ろの張り紙が読める（ヒントの紙）／③タオルの後ろに傷／④浴槽の栓をなくす／⑤洗面台の栓もない／⑥十円玉を洗面台の栓にして水を溜め、水で何かを溶かして「重たい何か」を得る→それで浴槽の栓ができる。

## A. 導入の手がかり（正規ルートの入口）

| 場所 | 操作 | 内容（**判断**＝仮の文章） |
|---|---|---|
| 便座 | 座る（既存の座る姿勢）→ 前を見る | 座った目線でだけ、ドアの内側の低い位置に貼り紙が見える。『湯は、ためてこそ。』 |
| 便器の後ろ | しゃがむ（既存の紙の位置） | 張り紙（ヒントの紙）『栓がない。軽いものは、浮く。』 |
| タオル | タオルをめくる／どける（調べる 2 回目） | 後ろの壁に引っかいた傷。丸い（十円玉の大きさ）くぼみと、その下に五本線（水の波）。傷の中に十円玉が挟まっている（拾える）。 |

調べた文章：タオル『タオルの後ろの壁に、傷がある。丸い形が、刻まれている。』／拾う『古い十円玉が、傷のくぼみに挟まっていた。』

## B. 栓の連鎖（すべて「水が溜まる」を軸にする）

```
十円玉（タオルの後ろ）→ 洗面台の排水口にふたをして水を溜める
   → 固形せっけん（棚の上）を水に沈める → 溶ける（約 30 秒。水でよい）
   → 中から鉛のおもり（重い）が出る → 洗面台の水を抜く（十円玉が戻る）
   → 浴槽の排水口に十円玉でふた＋おもりを載せる → 水がちゃんと溜まる
   → お湯はり／追い焚きが使える → バスロマンの玉が溶ける → ドライバー
```

- **浴槽の栓**：最初から**ない**。調べると『栓がない。穴から水が抜けていく。』
- **十円玉だけで浴槽の排水口にふた**をすると、すこし溜まるが、**十円玉が浮いてしまい**、水位が一定（低い高さ）より上がらない。お湯はり・追い焚き・入浴剤は**最小水位に届かず使えない**。『十円玉が浮いてしまう。重さが足りない。』
- **おもりを十円玉の上に載せる**と、ふたが安定し、水位が上がる。
- **洗面台の栓**：これも最初から**ない**。十円玉を排水口に置くとふたになり、水が溜まる（水を出したまま、が条件）。
- **固形せっけん**：棚の上のクリーナー・予備ロールの並びに追加（新規の小道具）。**水を溜めた洗面台に入れる**と、泡が出てゆっくり小さくなり、溶けきるとおもりが沈んで残る。『せっけんが溶けて、中から重たい鉛のおもりが出てきた。』
- ドライバー入りの玉（バスロマン）は、**お湯でだけ**溶ける（v3 のとおり）。

## C. 全体の順序（ゲート）

1. 手がかり（座る・しゃがむ・タオル）→ 十円玉
2. 洗面台に十円玉でふた → 水 → 固形せっけん → おもり
3. 浴槽にふた＋おもり → お湯 → バスロマン → 玉が溶ける → ドライバー
4. ドライバーの使い道（ドアノブ／鏡の戸棚→点検レバー／換気口の格子＋バケツの足場）

## F. 確認したいこと

1. 「**タオルの後ろ傷**」は、**壁の傷（手がかり）＋十円玉入り**という解釈でよいか。
2. 溶かす物は**固形せっけん→鉛のおもり**でよいか（別案：棚の固形洗剤、氷のようなもの）。
3. 浴槽のふたが浮く演出は、**水位の上限が低いまま**で表現する。
