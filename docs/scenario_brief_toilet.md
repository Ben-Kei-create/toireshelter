# シナリオ依頼資料：トイレ（ユニットバス）の謎解きルート たたき台

（ゲーム内の事実は、2026-10-13 時点のコードと文章から書き出した。「実装済」＝いまゲームに入っている。「未実装」＝まだない。）

## 0. 依頼したいこと

- **ユニットバス（トイレ・洗面・浴槽が一つになった小部屋）から出るまでの、謎解きのたたき台**をつくってほしい。
- いまは「手がかりの小さな紙」と「拾える物」が置いてあるだけで、**つながった謎解きにはなっていない**。ここに、筋の通った一本の流れ（できれば 2 本の分かれ道）を与えたい。
- 今回は**トイレ区画だけ**。自室・玄関・廊下・地下の謎解きは、あとで別に頼む。
- たたき台＝「完成した設計書」ではなく、**こちらで実装できる粒度の叩き台**（段取り・手がかり・文章案）。迷ったら案を 2〜3 個出して選ばせてほしい。

## 1. ゲームの前提（世界観と遊び方）

- 一人称視点の 3D（Godot）。**文字入力や数字の暗証はない**。操作は「歩く・見る・クリックで調べる・拾う・F で持ち物を使う」だけ。
- 主人公は**ユニットバスに閉じ込められて目が覚める**。目的は「ここから出て、部屋の外（5階の共用廊下）へ出る」。
- 部屋の外の廊下には、エレベーターと、西側に**下北沢の街並み（異世界）**が見える。
- 自室は細部が作り込まれた、少し奇妙な 1K（水槽・ラジオ・こたつ・床下の貯蔵庫・地下など）。**トイレの外は、遊べる物が多すぎるくらいある**ので、トイレ区画の謎は「外へ出る」ことに集中させたい。
- 文章の声は、**独り言のような一言。ちょっととぼけた・不安な空気**（例：「ドアノブが空回りする。開かない。」「『点検済。異常なし。たぶん。』……たぶん？」）。説明しすぎない。日本語のみ。
- 失敗（死・ゲームオーバー）は**ない**。詰まっても罰はなく、最初に戻るだけ。
- 「神の声」（かぎ括弧つき・うすい紫の字の独り言）が実装済み。**放置するとヒントとして出る**（5.6 参照）。

## 4. すでに仕込んである手がかり（小さな紙・見え方の仕掛け）

| 手がかり | 場所と見え方 | 文章 |
|---|---|---|
| **棚の裏の紙** | タンクの上の棚板の**裏**。**座る・しゃがむ（目線が棚板より下）と、見上げて読める**。立った目線では棚板に遮られる | 『下からなら見える。』 |
| **タンクの下の紙** | タンクの真下の壁。立つとタンクに、正面からは便器に遮られる。**しゃがんで便器の入口側から覗く**と読める | 『しゃがむと、いろいろ見える。』 |
| **浴槽の紙** | 浴槽の側面 | 『ここまで来たか。』 |
| **タオルの裏の傷** | タオルをずらす | 「タオルの裏に傷がある。前からあっただろうか。」 |
| **点検シール** | 天井の換気口の横（下向き） | 『点検済。異常なし。たぶん。』 |

→ **「しゃがむ」「座る」「下から見る」という見え方の仕掛けは、すでにゲームの語彙になっている**。これを謎解きの核に使うのがおすすめ（8-A）。

## 5. 仕組みとして使える機能（実装済）

1. **しゃがむ（C）**：目線が低くなる（0.6 m）。低い所の物や、見上げた裏側が見える。
2. **座る（E）**：便器に座ると目線が 1.12 m。ここからでないと見えない物を置ける。
3. **浴槽に入る（E）**：浴槽の底に立つ（水があっても入れる）。換気口を狙える。
4. **持ち物（最大 8 つ、1〜8 キー、F で使う）**：ドライバー、予備ロール、ユブロマンが既にある。**物を持って、対象を狙って F**が基本の「使う」。
5. **水の状態**：浴槽・洗面台に水位がある。栓と蛇口で変えられる。水がたまると「入浴剤を入れる」ができる。
6. **ヒント**：同じ場所で 55 秒動かず何もしないと、状況に合った**神の声の独り言**が 1 つ出る（出したヒントは二度と出ない、次まで 90 秒）。**新しい謎のヒントは、この仕組みに文章を足すだけで入れられる**。
7. **発見の知らせ**：「見つけた物」を初めて見つけたとき、右上に小さく「発見　○○　n / 22」と出る。謎の節目の演出に使える。
8. **セーブ**：持ち物・拾った物・直したドアなどを保存する（トイレの謎の状態も、必要なら保存に足せる）。
9. **文字送り**：メッセージは 1 文字ずつ出る。**短い文のほうが読みやすい**。

## 6. いまの脱出ルート（変えたくない前提／変えてよいか決めてほしい点）

- **脱出の条件**：玄関ホールの**玄関ドア（503）を開けて、外の共用廊下（5階）に出る**。トイレ→自室・ホールに出ただけでは脱出にならない。
- **裏技ルート（現状）**：落ちているドライバーでトイレのドアを直す → 玄関ホール → 玄関ドア。
- **正規ルート（現状）**：浴槽に入る → 換気口へ入る → ダクトを這う（角を 2 回）→ 外壁の出口でベランダへ降りる → ベランダの窓を開けて自室へ → 玄関ホール → 玄関ドア。
- 今回は、**「トイレから出るまで」を、この 2 本よりも筋の通った謎解きに作り替える**ことが依頼の中心。**2 本のルートを残すか、1 本に絞るか、新しい 3 本目を足すか**は、たたき台で提案してほしい（こちらで決める）。

## 7. 制約（実装できること・できないこと）

### 世界観・方針
- 神の声やメモは**日本語のみ**。長文の説明は避け、**一言の違和感**で導く（このゲームの持ち味）。
- **暴力・グロ・実在の商標名は避ける**（例：「UFOキャッチャー」は「つかみどり」と表記）。
- 脱出に「必須ではない遊び」（釣り・麻雀・レコード・ゲームなど）と、**謎解きの必須の流れは混ぜない**（遊びが詰まりの原因にならないように）。

### 実装の目安（コストの目安）
- **軽い**（そのまま足せる）：新しい調べる文章、新しい手がかりの紙、既存の物に「F で使う」を足す、拾える小物を 1〜3 つ足す、ヒント文章、既存の状態（ドア・鏡の戸棚・タンクの蓋・ホルダー・浴槽の水・カーテン・タオル）を条件にする。
- **やや重い**（少し作る）：新しい家具や仕掛けの 3D、アニメーションつきの新しい動き（例：床下に落ちた物を排水口から出す）、水と物の新しい相互作用。
- **重い／避けたい**：パズル用の別画面（数字盤・つまみ回し等の UI）、複雑な物理、物を動かして積むなどの自由度の高い操作、時間制限。
- **持ち物は最大 8 つ**（いま 3 つ、ほかの場所で別の物も使う）。トイレの謎で増やすなら **多くて 2〜3 つ**。
- **暗証・数字入力はない**。数字を使いたい場合は「読んで気づく数」（壁の紙・時計・ラベルなど）を、順番に押す・並べる形にしてほしい（入力 UI は作らない）。
- **カメラは一人称のみ**。「見る角度」「しゃがむ」「座る」は使える。

## 8. おすすめ（骨格案。たたき台のたたき台）

### 8-A．「見え方」の連鎖（既存の手がかりを活かす）【最有力】
1. 立ったままでは何も起きない（ドアは空回り）。
2. **座る／しゃがむ**と、棚の裏の紙『下からなら見える。』と、タンクの下の紙『しゃがむと、いろいろ見える。』に気づく。
3. しゃがんで便器の入口側から覗くと、**タンクの下の何か**（新しい手がかり：例えばタンクの裏の小さな鍵・紙片）が見える。
4. 取る → タンクの蓋を開ける／ホルダーの芯を替える／鏡の戸棚を開ける等、**既存の仕掛けの 1 つに「新しい状態」を与える**。
5. 最終的に、**ドアのネジ（ドライバー）か、換気口の格子**のどちらかを開ける。

### 8-B．「水」の連鎖（水位・栓・流す、を使う）
- 浴槽に水をためる → 栓を抜いて**流れる音・渦**で何かが排水口に現れる／洗面台の栓、タンクの水、便器の渦などを、順に使う。
- 入浴剤（ユブロマン）は「水がたまっている浴槽に入れる」という既存の操作がある。**色（ゆず色）が手がかり**になる案（例：お湯が黄色いとき、浴槽の底にだけ見える印）。

### 8-C．「交換」の連鎖（紙・芯・小皿・予備ロール）
- ホルダーの芯と予備ロールの交換は実装済み。「外した芯」を**小皿に置く**ところまで進む。
- 「**芯の中に何かが入っている／芯を別の場所に差す**」など、**拾う→使う**の 2 手で閉じる。

### 共通のおすすめ
- **手順は 3〜5 段まで**。1 段ごとに「違和感の一言（神の声）」→「気づき（発見の知らせ）」。
- **詰まったとき**は、放置ヒント（神の声）が段ごとに 1 つずつ出る形が親切（5.6）。**全段分のヒント文章**を用意してほしい。
- **ダミー（関係ない物）**は「飾り」の既存オブジェクトに任せる。**謎に使う物は 3〜4 個だけ**に絞り、他は「調べるだけ」の飾りにするのがバランスが良い。
- **正規ルート（換気口）と裏技ルート（ドア）は、同じ入り口から分かれる**形が望ましい（たとえば「同じ鍵を、ドアに使うか換気口に使うか」）。

## 9. ライターに決めてほしい／答えてほしいこと

1. この小部屋に閉じ込められた「理由」の味付け（偶然／誰かの意図／異世界の仕様）。**いまの紙の文面（『ここまで来たか。』など）は、誰かが先回りしている雰囲気**。誰が、何のために？
2. 謎の最終解は**ドア**か**換気口**か、**両方**か。
3. 主人公の持ち物をどの順番で増やすか（ドライバー、予備ロール、ユブロマン、コイン、新規）。
4. **神の声のキャラクター**（見守る／からかう／心配する）と、ヒントの段階（1 段目は遠回し→ 2 段目はやや明確）。
5. **新しく置きたい物・手がかり**（新規は多くて 3 つ）の案（名前・形・置く場所・調べたときの文章）。
6. 各段の**「気づいた」瞬間のメッセージ**（神の声で出すか、通常のメッセージか）。
7. **クリア直前の一言**（トイレから出るとき）。

## 10. 納品してほしい形（コピペして実装に渡す）

1. **全体の流れ**（箇条書き 3〜5 段。段ごとに「プレイヤーがすること」「見えること」「得るもの」）。
2. **新規オブジェクト／変更するオブジェクトの表**（名前／場所（上の座標系で）／調べたときの文章／使い方）。
3. **手がかり一覧**（どの紙・見え方が、どの段への手がかりか）。
4. **ヒント文章**（段ごとに 2 段階。各 40 文字以内。神の声の口調）。
5. **発見の知らせの名前**（右上に出る短い名前。1 段につき 1 つ。8 文字程度）。
6. **ルートの分岐**（正規／裏技／新規。どこで分かれるか）。
7. **詰まりそうな所と救済案**。
8. **案が複数あるときは、おすすめ 1 つ＋代案**。

## 付録 C．既存の「使えない」ときの文章

- 「ここでは使えない。」（持ち物を使えない対象に F を押したとき）
- 「出る場所がふさがっている。」
- 「先にカバーを開けよう。」／「まだ紙が残っている。」（ホルダー）
- 「もう少し水をためてから入れよう。」／「もう空っぽだ。」（入浴剤）
