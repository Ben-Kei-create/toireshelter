# 初見テスト 観察シート

**説明せずに遊んでもらう。** 横で観察し、操作と発言を書く。「難しいですか？」とは聞かない。

## 準備
- 試遊版を起動する（浴室から、最初の大きな異変＝ベランダまで）：
  ```sh
  TOIRE_PLAYTEST=1 TOIRE_SLICE=1 /path/to/Godot --path . 
  ```
  （書き出したビルドなら、同じ環境変数を付けて起動）
- 行動ログは `user://playtest/session_日時.jsonl` に残る（macOS: `~/Library/Application Support/Godot/app_userdata/Toiret/playtest/`）。
- 画面録画を回しておく。
- 開発用の近道（TOIRE_YEN100 など）は付けない。

## 遊ぶ前（1 分）
- 一言だけ：「気になったことは、声に出して言ってください。説明はしません」。
- ゲーム慣れ：普段、脱出ゲーム／一人称ゲームを遊ぶか（はい・いいえ）。

## 見る 4 つ
1. **最初の発見までの時間**（最初に「おっ」と言った／立ち止まった時刻）：　　分　　秒
2. **同じ失敗の反復**（同じ場所・同じ操作を何度もした）：場所＝　　回数＝
3. **助けを求めた場所**（「どうするの？」「これ何？」と聞かれた時刻・内容）：
4. **やめたくなった瞬間**（ため息・時計を見る・「次どうしよう」・手が止まる）：

## 遊んだあと（聞くなら、これだけ）
- いちばん印象に残った場面は？
- 「続きを遊びたい」と思ったのは、どのあたり？（言われたら、そのまま書く）
- この部屋は、どんな場所だと思った？（一言）

## 行動ログの見方（私が集計できる）
- `discover`：発見の時刻。最初の発見までの時間 = 最初の `discover` の `t`。
- `interact` の `n`：同じ対象を 5・10・20 回調べたら、迷っているしるし。
- `idle`：25 秒の無操作。どこで止まったか（直前の `message` の text）。
- `message`：直前に読ませた文章（冒頭 40 字）。
- `slice_end`：試遊の最後まで着いた。なければ、途中でやめた（最後の行がやめた時点）。
