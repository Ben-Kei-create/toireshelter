# 次にやること（レビュー 7 点を受けた方針）

レビューの核心：**「狭い日常空間が、だんだんおかしくなる」こと**を中心に、操作・謎・美術を揃える。
遊びが増えすぎたので、足す段階は終わり。**削る・揃える・初見で確かめる**段階に入る。

## 0. 紹介文（一文）— あなたが決める

案（どれかを選ぶか、書き換える）：

1. 「いつものユニットバスを調べるほど、自分の部屋の異常に気づいていく脱出ゲーム」
2. 「トイレに閉じこもっていた。インターホンが鳴る。ドアは開かない。——部屋が、少しずつ、おかしい」
3. 「水と光と目の高さで、狭い部屋の“ほんとうの形”を暴く、一人称の脱出ゲーム」

この一文に**効いていない要素**は、削るか、任意の寄り道に落とす（下の「採否表」）。

## 2. 私（Claude）がやること

### A. 反復を削る（5 章・すぐ着手できる）
- [ ] 隔て板：大きなツルハシは **5 回**で割れる。小さなツルハシは**ジョークとして**「1994 回まで数えるが、100 回目で“気が遠くなって”割れる」に（演出で笑いに置き換える）。
- [ ] 給水待ち：謎に必要な水位（せっけん 40％・玉の溶解）までの時間を短く（満水 40 秒→20 秒、溶解の秒数も 8→5）。待つ間の変化（泡・湯気・波）を足す。
- [ ] クレーン：1 回目の演出は残し、2 回目以降は短縮済み。**景品 8 回すべて同じ演出**をやめ、5 回目以降はスキップ可。
- [ ] 麻雀・釣りの“待ち”も同様に点検。

### B. 身体感覚と合わせる（2 章）
- [ ] **しゃがんだら**、設定の身長に関係なく、低い所（ねずみ穴・ベッド下・こたつの隙間）が見える。→ ねずみ穴は対応済み。**ほかの低い謎（鏡の曇り止め）も同じ規則に**。
- [ ] 身長設定は「掛け軸の影絵（142 cm）」「自販機（150 cm）」など**特殊能力**として、序盤で一度体験させる（身長計のシール＋「[ ]」の案内を、最初の浴室で出す）。
- [ ] 序盤の 2〜3 分で**目の高さを変えて景色が変わる**小さな発見を入れる（浴室ドア枠の身長計）。

### C. 謎の「事前の納得材料」を点検する（3 章）
謎ごとに「観察→仮説→試す→反応→理解」の表を作り、足りない所に手がかりを足す。**初稿の表（私が埋める）：**

| 謎 | 観察（事前の手がかり） | 足りない所 | 足す案 |
|---|---|---|---|
| せっけん→おもり | 洗面台の下のせっけん、ふた、水 | せっけんの中に何か（影） | せっけんの拡大に「重い」「影」。溶けるたびに縮む見た目（済）＋拡大で透ける影 |
| 悪口本を流す | 黒塗りの本 | 「水に流す」との結びつき | 本の文面・最後のページの滲み、トイレ（便器）の近くの紙のメモ |
| 芯＋結晶→望遠鏡 | 天井の点（寝ると気になる） | 芯と結晶を合わせる理由 | 天井の点は“遠くを見たくなる”描写。結晶は「のぞくと透ける」説明 |
| 白紙トランプ | 青い光 | 金庫との結びつき | 金庫のくぼみのふちに点の並び（虫眼鏡で見える・済）。トランプに「重い順」の落書き |
| 吹き矢 | 景品「吹き矢の部品」 | 的の存在 | 向かいの壁の的に、最初から気づける（背伸びで見える）合図 |
| 黒電話 7305 | カーテンの数字 | 電話との結びつき | 電話のメモ帳に「ぬれたカーテン」など |

### D. 意思を飛び越える演出を直す（4 章）
- [ ] カーテン→松明を捨てる：**押す前に一拍**（「カーテンを開けると、松明が風で消えそうだ。開ける？」の予告／または自分で窓の外へ投げる操作にする）。
- [ ] 境界を越えると結末（お隣の窓・玄関）：**予告は入れた**。玄関も「ここを出たら終わるかもしれない」を出す。
- [ ] 演出中の中断・保存・再開：取引中は保存を後回し（済）。**追加**：エレベーター・結末の途中の保存。

### E. 美術の編集（6 章）
- [ ] 重要物の周囲に**余白**（本棚・小物の“クラスター”を整理）。重要物（鍵・コイン・メモ）の**明度差**ルールを決めて全部に適用。
- [ ] **文字は全点、実際の表示サイズで撮影して確認**するスクリプトを作る（私）。読めない文字は拡大表示で救う。
- [ ] 色の整理：トイレの宮殿配色を基準に、**自室・和室も“彩度と汚れ方”のルール**（清潔／生活感／古さ）を決める（あなたの判断が必要）。
- [ ] AI 素材の採用後の編集（色調・汚し・縮尺）。

### F. 初見プレイのための道具（7 章）
- [ ] **プレイテスト用ビルド**：
  - 開始から最初の「大きな異変」（浴室が上がる〜ベランダ）までに絞った**短い版**。
  - 開発用の近道（コイン付与など）を無効化。
  - **行動ログ**を自動で残す（最初の発見までの時間、同じ操作の反復回数、無反応のクリックが続いた場所、放置時間、やめた時点）。
- [ ] **観察シート**（あなた用）：時刻・発言・操作・つまずき・「やめたくなった瞬間」を書く表。私が作る（docs/playtest_sheet.md）。
- [ ] macOS / Windows のビルドの書き出し（私）。

## 3. あなたがやること

1. **紹介文を決める**（上の案から、または書き換え）。
2. **採否表**を見て、削る・任意にする要素に印をつける。
3. **初見の人を 5 人**集める（友人でよい。ゲーム慣れの度合いを混ぜる）。
4. **説明せずに**遊んでもらい、横で観察する（画面録画があるとよい）。
   - 記録：①最初の発見までの時間 ②同じ失敗の繰り返し ③助けを求めた場所 ④やめたくなった瞬間。
   - 「難しいですか？」と聞かない。操作と発言を書く。
5. 物語の意図の確認：**閉じ込めたのは誰か／コタニとは／おばあちゃんはなぜ**は“最後までわからない”で確定か、続編の余地か。
6. 文章（`docs/texts_all.md`）のリライト。書き換えた行を教えてくれれば反映する。
7. コントローラ実機での確認（持っていれば）。

## 5. 今後の展開（順序）

1. **垂直スライスを磨く**：浴室 → 最初の大きな異変（浮上・暗闇・ベランダ）。ここだけ初見に遊ばせられる状態にする（2 章 B・D・E、F）。
2. **初見テスト（5 人）**。記録をもとに、**直す／削る**を決める。
3. **後半を“任意の寄り道”に再編**：麻雀・釣り・TV ゲーム・ヘッドホンなどを、**中心の体験から外し**、**通常クリア**と**真のクリア**の道筋を短く保つ。
4. **謎の手がかりの再点検**（2 章 C の表を全部埋める）。
5. 美術の統一（色・汚れ・文字）と、画像差し替え。
6. 紹介動画・ストアページ用の素材。
7. 余力があれば：**物語の核**（インターホン・おばあちゃん・コタニ・閉じ込めた誰か）を、メモ・日記・ヘッドホンの声で**一本の筋**にまとめる（ネタバレは伏せたまま）。
