# 画像素材の記録

ゲームに貼る画像は `assets/textures/` に置く。用途・寸法・UV はこのファイルで管理し、画像そのものに説明は入れない。

## 共通の取り込み設定

- 形式：PNG（sRGB、透過なし）
- Godot の取り込み：ロスレス（`compress/mode=0`）、ミップマップ有効（`mipmaps/generate=true`）。設定は各 `.png.import` に保存してある
- マテリアル：`StandardMaterial3D` の `albedo_texture` に設定し、`texture_filter = LINEAR_WITH_MIPMAPS_ANISOTROPIC`（`room.gd` の `_texture_mat()`）
- 陰影はゲーム内の照明だけでつける。画像に陰影は焼き込まない

## 一覧

### door_poster_plumber.png — ドア内側の広告（架空の「ひだまり水道」）

| 項目 | 内容 |
|---|---|
| 用途・場所 | ユニットバスのドアの部屋側の面。`DoorPivot/Visual/Poster`（開閉に追従） |
| ゲーム内寸法 | 幅 0.25 × 高さ 0.354 m（A判比 1:1.414） |
| 位置 | ドアのローカル座標で蝶番から x=0.32 m、中心の高さ 1.40 m、扉面から 2 mm 手前 |
| 解像度 | 768 × 1086 px |
| メッシュ・UV | `QuadMesh`（片面）。UV 0〜1 に画像1枚、繰り返しなし |
| 調べる判定 | `DoorPivot/PosterCollision`（Area3D、interact レイヤー、厚さ 6 mm）。`interact_id = "poster"`。広告の外側はドアの判定に当たる |
| 出典 | ChatGPT の画像生成で作成（生成 AI 使用）。原寸 1055×1491 の WebP を macOS `sips` で 768×1086 に縮小（比率はほぼ同じなのでトリミングなし） |
| 内容 | 架空の業者名。実在の企業名・ロゴ・電話番号は含まない。テープ留めと紙の汚れは画像に描かれている |
| 既知の問題 | 「お困りごと」の「困」の字形が崩れている（「木」の部分が別の形になっている）。生成画像由来。差し替える場合は同じファイル名・同じ解像度で上書きすればよい |

### yubroman_label.png — 粉末入浴剤のラベル（架空の「ユブロマン ゆずの香り」）

| 項目 | 内容 |
|---|---|
| 用途・場所 | 便器タンク上の容器 `BathPowder/Visual/Label` に巻く |
| 容器 | 本体 直径 0.10 × 高さ 0.15 m（`Body`）、クリーム色の蓋 直径 0.104 × 高さ 0.025 m（`Lid`、別ノード）。底面はタンク上面 y=0.925 に接する |
| ゲーム内寸法 | 円周 0.317 m（半径 0.051 m）× 高さ 0.10 m。本体の高さの中央に巻く |
| 解像度 | 1024 × 320 px（3.2:1） |
| メッシュ・UV | ラベル専用の蓋なし円筒帯（`room.gd` の `_label_band()`、48 分割）。u = 円周方向 0〜1、v = 上 0〜下 1。u=0.5（文字のある中央）を +x（通路側）、u=0/1 の継ぎ目を −x（壁側）に向ける。繰り返しなし |
| 調べる判定 | `BathPowder/Collision`（円柱、world レイヤー）。`interact_id = "bath_powder"` |
| 出典 | ChatGPT の画像生成で作成（生成 AI 使用）。原寸 2000×667（3:1）の WebP を、上下 21 px ずつトリミングして 2000×625（3.2:1）にし、1024×320 に縮小。横に引き伸ばさないための処理で、トリミングした部分に文字はない |
| 注意 | 左右の端の模様は完全にはつながらないため、継ぎ目は壁側に向けてある |

### towel_fabric.png — タオルの布地（繰り返し）

| 項目 | 内容 |
|---|---|
| 用途・場所 | 左の壁のタオル掛けのタオル `TowelBar/Towel`（手前・奥の布、上の丸い折り返し、裾の縁取り） |
| 解像度 | 512 × 512 px、継ぎ目なしで繰り返す |
| 貼り方 | `MeshKit.tiled_mat()`：トリプラナー投影で 0.2 m 四方に1枚。箱・円柱のどの面でも同じ細かさになる。裾の縁取りは同じ画像を暗く着色（`albedo_color` 0.78/0.8/0.84） |
| 形 | 折り返しや厚みはメッシュ（2枚の板＋円柱）で表現。布の物理シミュレーションはなし |
| 出典 | ChatGPT の画像生成（生成 AI 使用）。2枚組の画像（1536×1024）の左側。灰色の背景と英語の説明文を除き、枠の内側 880×880（x 55〜934, y 34〜913）を切り出して 512×512 に縮小（Lanczos） |
| 継ぎ目の調整 | 縮小しただけの画像は、2×2 に並べると縦横の境目に線が見えた。半分ずらした画像と、端から約50 pxで切り替わるように混ぜて継ぎ目をなくした（Godot の Image 処理で実施） |

| 項目 | 内容 |
|---|---|
| 用途・場所 | 鏡の下の棚に寝かせたチューブ `SinkShelf/Toothpaste/Label` |
| 解像度 | 271 × 512 px（元の縦横比を維持） |
